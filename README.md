# Math Research

Rules and procedures for mathematical research and paper integration with Codex.

Version: **0.2.1**

| Language | Project rules | Research procedure |
| --- | --- | --- |
| English | [AGENTS.md](en/AGENTS.md) | [SKILL.md](en/SKILL.md) |
| 简体中文 | [AGENTS.md](zh-CN/AGENTS.md) | [SKILL.md](zh-CN/SKILL.md) |

Select one language. Copy its `AGENTS.md` to the root of your research project.
The project rules can operate alone. `SKILL.md` supplies an optional detailed procedure.
Read the complete rules before work if your tool supplies only part of the file.

Version 0.2.0 adds paper integration with originality checks and a shared project fact graph.
Each formal submission includes a separate `PROOF_IDEA.md` explanation.
Paper tasks use `out_papers/`; research rounds retain their own budgets and recovery rules.
