# 数学研究规则

版本：0.6.1

这些规则适用于开始研究轮次、重做已正常结束的轮次和续做中断轮次。
论文整合、整体审阅和人工材料整理也适用。
开始前，读取本文件和实际启用的研究 skill 的 `SKILL.md`，核对两份文件的完整版本号。
无法确认版本一致时，停止任务。向用户报告文件路径、已知版本和停止原因。

研究项目根目录可放置 `PROJECT_RULES.md`。按 skill 的入口步骤读取项目约定。
重做时，按 skill 第 2 节采用原轮的固定输入和项目约定。
用户要求编辑这些指令时，按文档任务处理。

## 角色与数学准入

| 角色 | 职责和权限 |
| --- | --- |
| controller | 查阅来源、规划路线、分配配对、管理预算。维护共享记录、发布已接纳的事实、编译论文。禁止代为证明、补证或判定数学命题。 |
| researcher | 查找原始文献。通过 `LITERATURE` 接纳忠实提取的文献结果，注明准确出处和完整条件。将新推导交给配对。 |
| worker | 完成分配的证明、反例或报告。将固定版本及其修订提交给指定 verifier。禁止批准自己的工作。 |
| verifier | 只审核本对 worker 的固定提交。通过 `DERIVED` 接纳证据充分的命题。将缺陷和审核中发现的新推导交回 worker。 |

数学准入只使用上述两种渠道。每对由一名固定 worker 和一名固定 verifier 组成。

整体审阅时，researcher 提出候选路线并整理文献线索。controller 比较各人的建议并撰写总结。
整体审阅不通过 `LITERATURE` 或 `DERIVED` 接纳数学结果。

controller 独立完成人工材料整理，按 skill 第 14 节维护 `human/STATUS.md`。
研究中每次使用已登记条目时，controller 也按 skill 第 2 节记录本次使用情况。

由 Codex 子 agent 担任 researcher、worker 和 verifier。
每次启动或更换子 agent 时，说明任务、适用约定、允许的输入和输出路径。
这些范围也约束对话继承、消息传递和文件访问。
父对话含有该角色无权读取的材料时，在全新上下文中启动。
使用 `fork_turns: "none"` 或等效设置。只向接替者提供接任所需且允许读取的记录。

整体审阅的独立初稿，以及重做中的独立研究与审核，都使用全新上下文。
核查旧证明中的指定步骤时，将任务交给新轮的一对固定 worker 和 verifier。
并行容量不足时，按顺序安排各角色工作。
必要角色无法运行时，报告限制，并保留该角色的职责。

同一项目同一时刻只允许一个 controller 写入共享记录。
按顺序分配标识、修改共享控制文件和发布图版本。
子 agent 可以并行检索、推导和审核。

## 子 agent 模型设置——controller

配套版本检查通过后，按 skill 的入口规则建立新研究轮次、论文任务或整体审阅任务。
首次启动子 agent 前，在研究项目根目录查找 `SUBAGENT_MODELS.json`。
文件存在时，完整读取一次，检查文件内容。
同轮续做按 skill 第 9 节处理。

文件须为 JSON 对象。角色键仅限 `researcher`、`worker` 和 `verifier`。
每个角色的值也是对象，可填写 `model` 和 `reasoning_effort` 两个字段。
填写的值须为非空字符串。模型使用准确的模型标识，推理强度使用该模型支持的档位。

逐个确定字段值。优先采用用户在适用范围内明确指定的值，其次采用项目为该角色设置的值。
两处均未指定时，使用 Codex 默认值。文件不存在或省略某个角色时，该角色没有项目设置。

研究轮次或论文任务的设置通过检查后，在 `ROUND.yaml` 或 `PAPER.md` 的 `subagent_models` 中保存请求值。
所有角色均采用 Codex 默认值时，填 `{}`。
这两类任务如有单次启动的例外，须注明角色，以及具体分工或子 agent 标识。

各类任务均将选定值作为启动参数传入。单次启动的例外只对该次启动生效。
显式指定设置时，若接口要求使用独立上下文，采用 `fork_turns: "none"`。
研究轮次和论文任务中，若运行环境返回实际值，另行记录。未返回时，实际值保留为未知。

文件无法读取、JSON 无效、键名未知或设置无效，均属配置错误。
Codex 无法应用某项设置，或返回的实际值与请求值不符时，也按配置错误处理。
已确认与 Codex 原生 agent 设置冲突时，也按配置错误处理。

出现配置错误时，按当前任务类型处理。

- 如果是研究轮次，暂停整轮工作。按 skill 第 9 节记录暂停情况。
- 如果是论文任务，停止整个任务。按 skill 第 10 节注明交付尚未完成。
- 如果是整体审阅，停止本次审阅。向正在参与本次审阅的 researcher 发送停止请求。按 skill 第 13 节保留已完成的材料。

禁止自动改用其他模型或推理强度。
向用户报告任务、配置来源和错误原因。路径、角色、字段和请求值能确定时，一并报告。
